## WS-02 ssrf-guard (W1, `feature/browser-ssrf-guard`)
**File:** `src/server/browser/{ssrf.ip,ssrf.proxy,ssrf.allowlist,navigation.guard}.ts` + test §5.
**Perilaku:** `classifyIp(ip)` (IPv4/IPv6, mapped, CGNAT, link-local, ULA, 0.0.0.0) -> `'public'|'private'`. `startSsrfProxy({port?:0, allow, resolver})` pada `127.0.0.1`: tangani `CONNECT host:port` dan request absolut HTTP; resolve DNS sendiri (`node:dns` yang bisa diinjeksi), semua IP hasil harus lolos klasifikasi atau ada di allowlist `host:port`; sambung ke IP tervalidasi (bukan ulang resolve); tolak 403 dengan alasan tanpa URL; log `warn` hanya hostname. `parseAllowHosts(env)`: format `host:port`, ditolak seluruhnya jika memuat port webterm (`PORT`) pada loopback (hard-deny). `navigation.guard`: `check(url)` skema + host (tanpa DNS) dan `onFrameNavigated` memverifikasi ulang; keluaran `BlockReason`.
**Test:** §5 WS-02 (termasuk resolver palsu rebinding dan server tujuan lokal Bun). **Selesai bila:** semua rentang privat ditolak, proxy bukan open relay, tak ada nilai literal selain konstanta/kontrak.

## WS-03 cookie-vault (W1, `feature/browser-cookie-vault`)
**File:** `src/server/browser/{cookieVault.store,cookieImport.parse,cookieImport.preview,cookieRedact,profile.paths}.ts` + test §5.
**Perilaku:** vault AES-256-GCM (`node:crypto`), IV acak, kunci 32 byte dibuat via `SecretStore` (`src/server/envSecrets.store.ts`) dengan kunci `WEBTERM_BROWSER_VAULT_KEY`; blob `dataDir()/browser/vault/<workspaceId>.enc` mode 0600, dir 0700; `save/load/clear(domain?)/listDomains`; TTL dengan jam injeksi. Parser `storageState` (Playwright) dan Netscape `cookies.txt` -> model internal; batas ukuran; galat tanpa membocorkan isi. `preview`: map `previewId -> cookies` in-memory dengan TTL, `take(previewId, domains)`. `cookieRedact`: satu-satunya pembentuk log `{workspaceId,domains,count,action}`. `profile.paths`: hanya path di bawah `dataDir()`, tolak traversal `workspaceId` (pola ID aman).
**Test:** §5 WS-03 (canary nilai cookie tak boleh muncul di log/galat/JSON respons). **Selesai bila:** tamper terdeteksi, izin file benar, tidak ada `console.*` dengan data cookie.
